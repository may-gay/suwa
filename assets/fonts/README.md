# Fonts

Maple Mono is embedded in the native app and used for all interface text.
No font service is contacted at runtime.

- Maple Mono Regular: body, controls, small labels, and shortcut keys.
- Maple Mono Bold: branding and headings.

The OTF files come from Maple Mono 7.9 (the local `maplemono-otf` package).
[Upstream source](https://github.com/subframe7536/maple-font).
The SIL Open Font License is included in `LICENSE.MapleMono`.
